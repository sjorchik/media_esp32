================================================================================
                     ШПАРГАЛКА З GIT ТА GITHUB
================================================================================

[1] ПОЧАТКОВЕ НАЛАШТУВАННЯ GIT (Виконується 1 раз після встановлення)
--------------------------------------------------------------------------------
1.1. Встановити пошту, прив'язану до GitHub:
git config --global user.email "your_email@example.com"

1.2. Встановити ім'я або нікнейм:
git config --global user.name "Your Name"


[2] ПЕРШЕ ЗАВАНТАЖЕННЯ НОВОГО ПРОЕКТУ НА GITHUB
--------------------------------------------------------------------------------
(Створіть порожній репозиторій на GitHub, потім відкрийте термінал у папці проекту)

2.1. Ініціалізація Git у папці проекту:
git init

2.2. Додати всі файли папки до відстеження:
git add .

2.3. Створити перший коміт:
git commit -m "Initial commit"

2.4. Перейменувати головную гілку на main:
git branch -M main

2.5. Прив'язати локальну папку до репозиторію на GitHub:
git remote add origin https://github.com/USER/REPOSITORY.git

2.6. Відправити код на GitHub:
git push -u origin main


[3] ОНОВЛЕННЯ КОДУ НА GITHUB (Після внесення змін у файли)
--------------------------------------------------------------------------------
3.1. Зафіксувати всі нові та змінені файли:
git add .

3.2. Створити коміт з описом змін:
git commit -m "Updated files"

3.3. Відправити оновлення на GitHub:
git push


[4] ВИБІРКОВЕ ДОДАВАННЯ ФАЙЛІВ ТА ПАПОК (Без git add .)
--------------------------------------------------------------------------------
4.1. Додати лише один файл:
git add main.cpp

4.2. Додати декілька конкретних файлів:
git add main.cpp display.h config.h

4.3. Додати окрему папку з усім вмістом:
git add Drivers/

4.4. Додати всі файли з певним розширенням (наприклад, .cpp):
git add *.cpp

4.5. Ігнорування непотрібних файлів (.gitignore):
Створіть файл .gitignore у папці проекту та впишіть туди папки/файли:
build/
Debug/
*.exe
*.hex


[5] ВИРІШЕННЯ ПОПУЛЯРНИХ ПОМИЛОК
--------------------------------------------------------------------------------
5.1. Якщо на GitHub вже є файли (README, license) і push відхилено:
git push -u origin main --force

5.2. Якщо виникає помилка "error: remote origin already exists":
git remote set-url origin https://github.com/USER/REPOSITORY.git

5.3. Перевірити поточний стан файлів та гілки:
git status

5.4. Перевірити прив'язане посилання на репозиторій:
git remote -v
